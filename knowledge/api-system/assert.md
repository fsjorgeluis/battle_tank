## Contrato

```lua
assert(condition, [message])
```

## Semántica

Comprueba una condición y detiene el programa con un mensaje si es falsa. Es una herramienta de depuración: las aserciones expresan invariantes que el código debería garantizar.

## Parámetros y retorno

- `condition`: expresión que debe ser verdadera.
- `message` (opcional): texto impreso al fallar la condición.
- Retorno: no especificado por la fuente.

## Efectos y límites

- Detener el programa con aserción fallida es la forma de capturar errores de corrutinas: `ASSERT(CORESUME(C))`.

## Ejemplos relacionados

`ASSERT(addr >= 0 AND addr <= 0x7FFF, "OUT OF RANGE")` valida una dirección antes de `POKE`.
